# Fazendinha — demonstração

Demonstração gratuita do app infantil de colorir **Fazendinha**: só o pasto está aberto. A fazenda completa estará no app para iPad.

Acesse: https://sandroldias.github.io/fazendinha-demo/

Este repositório guarda apenas a versão publicada (gerada por `flutter build web`); o código do app fica em um repositório privado.
